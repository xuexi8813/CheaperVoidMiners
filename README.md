# Cheaper Void Miners for GTNH

A Cheaper Void Miners fork for GTNH 2.9.0/2.9.1, with early-game void mining, five tiers of fluid drillers, three Void Miner EX tiers, two non-electric wooden machines and a Surface Planetary Gas Siphon.

## 项目定位

面向 GTNH 2.9.0/2.9.1（MC 1.7.10，开发运行时对齐 2.9.1）的 kuolemax/CheaperVoidMiners 降档加强分支。早期即可虚空采矿，矿石和流体产量随机器升级提高。

## 机器清单（11 台）

### 虚空矿机 EX I / II / III（多方块）

- LV / HV / IV 档，沿用上游 `TIER_MULTIPLIER`（4 / 8 / 16），产量额外 ×16。
- 取最高单仓电压档：每高于本机一级，产量 ×4；低于或等于本机档位不加成。与 ×16、气体和批量叠乘。仅算电压加成：EX I 用 HV 仓 ×16、UV 仓 ×16384；EX III 用 UV 仓 ×64。
- 输入惰性气体可增产：氖 ×4 / 氪 ×8 / 氙 ×16 / 鿫 ×64。
- 沿用 GT 虚空矿机机制，支持维度覆写与白名单/黑名单。

### 虚空流体钻机（五档，多方块）

- 铁 LV / 钢 MV / 钛 HV / 硅岩 LuV / 无尽 UV。
- 无需采矿管道或流体输入仓，抽取地下流体不耗尽区块储量。
- 每 100 tick 产出 1000 mB × 4^(输入电压档 − LV + 1) × 16^(机器阶级) × 4^(钻头阶级 + 1)，机器阶级从铁档 0 起。电压项按 GT 档位倍增（LV=4、MV=16、HV=64、EV=256、IV=1024、LuV=4096、ZPM=16384、UV=65536、UHV=262144）；无尽钻机的电压项底数为 16（每档 ×16）。
- 能源仓接受 LV 及以上档位，取最高可用输入档。
- 按输入电压档消耗 1 A，与机器档位无关。
- 输入总线取最高阶钻头：铁 ×4 / 钢 ×16 / 钛 ×64 / 硅岩 ×256 / 无尽 ×1024；无钻头不加成。周期成功启动时有 0.1% 概率消耗 1 个。
- 控制器放维度显示方块可指定维度，留空用当前维度。输入总线的编程电路配置 1..N 选该维度流体表第 N 项（见 NEI）；配置 0、无电路或越界均不启动。
- 控制器 GUI 切换销毁模式：默认销毁过量流体；不销毁时输出仓满则待机，腾空后恢复。

### 木质两机（无电单方块，GT 标准小机器形态）

- **木质虚空矿机**：每 100 tick 产出一组主世界矿石（64 件，占 1 槽），不破坏方块。6 个输出槽满时待机，可手取或用传送带。GUI 幽灵电路槽：1..N 选矿脉及其贫瘠矿，N+1 选贫瘠矿池，0 或无电路按生成权重混合，越界待机。
- **木质虚空流体泵**：每 200 tick 向内罐抽取 100 mB 主世界地下流体。GUI 幽灵电路槽配置 1..N 选流体；配置无效、罐满或流体不兼容时待机。合成需原木、青铜中型流体管道和烧制粘土桶（Iguana Tweaks）。

### 地表行星气体钻机（多方块）

- 可建在任意维度地表，无需轨道空间站。沿用原版 13×23×13 结构：行星虹吸机械方块、钨钢框架、强化镀铑钯机械方块和加热线圈。
- 气体不受所在维度限制。原版 16 种气体（4 行星 × 4 深度）按行星 Tier 升序编号，同档按内部 ID 排序。启动须在输入总线放入有效的编程电路（1..N）；具体配置看 NEI 配方，不按列表行序。
- 单周期基础产量按旧版实际基准周期 9t 的产速折算至 200t（旧基础量 × 200 ÷ 9，向下取整至 mB），NEI 展示同一基础量；实际产量再乘以 16^max(0, 机器电压档 − 行星 Tier) 并计入钻头和超频。行星 Tier 高于机器电压档的气体不可选。EU/t = Depth × 4^(行星 Tier + 2) 按原版公式与无损超频规则（每级产量 ×2、耗电 ×4），**不随 16^ 产量加成放大**。
- 钻头倍率同虚空流体钻机，取最高阶；每次成功启动只判定一次 1% 消耗概率，批量启动也只判定一次。
- 基准周期 10 秒（未计线圈加速），加热线圈仍是必需部件，沿用原版加速曲线；Mining Pipes 的需求不变。本机批量时长预算按 `floor(128 × 200 ÷ 9) = 2844t` 换算，只合并预算内的整周期。原版的轨道空间站 chunk loading 随空间站限制一并移除。
- 开启流体输出保护时，只要输出仓能接收至少 1 mB 就可开工。完工气体按仓体实际接收量逐 tick 排出；剩余量可跨重载保存，排完才启动下一轮。允许销毁时可丢弃溢出，但切换模式不会丢弃已完工的受保护气体。
- 组装机：硅岩虚空流体钻机、原版行星气体钻机、坚固钨钢机器机壳 ×8、钨钢框架 ×8、超级储罐（IV）、电泵（LuV）、硅岩钻头、编程电路 1（不消耗）。

## 多方块结构

- 流体钻机和 EX 矿机沿用 GT 流体钻井机的 3×3×7 结构，控制器在正面底层中央。
- 流体钻机的机壳与框架随档位变化：铁档用 ULV 机壳，硅岩档用坚固钨钢机器机壳，无尽档用中子素采矿机壳。
- 流体钻机组装机配方：机壳 ×4、GT 框架 ×4–8、超级缸、电泵、钻头、编程电路 12（不消耗）。框架数和时长随档位增加。
- EX 矿机无序合成（1:1）：GT 采矿机 LV（Basic Miner）→ EX I，GT 采矿机 HV（Advanced Miner）→ EX II，矿石钻井机 Mk I 控制器（Ore Drilling Plant）→ EX III。
- 木质虚空矿机工作台配方：原木 ×6、燧石 ×2、木棍 ×1。3×3 中列放燧石、木棍、燧石，其余放原木。

## 内置维度覆写（合并自 Void-Miner-Tweak-Mod）

- 在 EX 矿机控制器放入 GTNEI 维度显示方块，切换到有矿表数据的目标维度。未注册的私人维度无矿表时仍可打开过滤器。
- 安装独立版 vmtweak 时自动让位；移除后接管并迁移旧存档 NBT。

## 矿石过滤器

- EX 矿机的白名单和黑名单按**矿物材料和矿石类别**匹配：同类别不限围岩，普通矿和小矿（贫矿）分别筛选。无法识别材质的物品仅按物品、元数据和 NBT 精确匹配。
- EX 的 GUI 勾选和输入总线矿石取并集；总线可放入小矿（贫矿）。切换覆写维度时，GUI 列表自动刷新。
- 普通虚空矿机仍按矿物材料宽匹配，不区分围岩或大小矿。

## NEI 支持

- 流体钻机按维度列出流体；木质矿机按矿脉列出矿物及其贫瘠矿。
- 地表行星气体钻机每种气体一条配方，显示编程电路配置、钻井深度 × 64 根采矿管道和基础产量。

## 兼容性

- **双端必需**：客户端和服务器均须安装，缺一端会被 FML 握手拒绝。
- **GT-Miao-Blueprint 蓝图投影仪**：按类缓存多方块结构，使用 GT 注册的机壳贴图索引。

## 本地化

- 机器名、GUI 和提示均有 zh_CN 翻译；GT 语言覆盖文件自动写入游戏根目录，无需额外语言包。

## 构建

```bash
./gradlew build        # 完整构建（发布 jar）
./gradlew runServer    # 开发环境服务器冒烟
```

- Gradle 按 `gradle/gradle-daemon-jvm.properties` 选用 JDK 25；Jabel 输出兼容 MC 1.7.10 的 Java 8 字节码。
- GT5u、ModularUI2、NEI 等依赖来自 GTNH Maven；开发运行时对齐整合包版本。

## CI

- push / PR 到 master / main 自动构建与测试。
- 版本 tag 触发 GitHub Release 发布。
